# 이미지 뷰어 검증 · 2026-10-14

Android 11(API 30)·16(API 36) ARM64 에뮬레이터에서 각 10개 부하 시나리오가 통과했습니다. 합계 600회 페이지·확대·배치·반전 조작과 200회 문서 재열기를 검사했습니다. 각 환경의 이미지/TXT/PDF 회귀 검사 20개도 통과했습니다.

## 자료와 조건

ZIP은 100MiB·300MiB·1GiB, RAR5와 7Z는 각각 일반·솔리드 300MiB입니다. 자체 제작한 고유 1536×2048 JPEG의 실제 이미지 데이터로 용량을 채웠으며 빈 데이터로 부풀리지 않았습니다. 같은 JPEG 묶음을 압축 형식별로 사용합니다. 거대 이미지 시나리오는 1440×40000 PNG와 12000×12000 JPEG를 검사합니다. 폴더 시나리오는 작은 JPEG 1,000/10,000장을 실제 파일로 생성해 항목 수 영향을 분리합니다.

앱과 테스트는 debug APK이며 실제 ImageSource·격리 작업 프로세스·타일 뷰를 사용합니다. API 30은 1080×2280, API 36은 720×1600이고 density는 320입니다. 두 AVD를 함께 실행했으므로 두 OS의 속도 비교나 실물 기기 성능 지표로 해석하지 않습니다. OS 파일 캐시는 비우지 않았습니다.

각 시나리오는 앱의 이미지 시험 캐시를 비운 뒤 시작합니다. 첫 타일 표시 시간에는 원본 복사·해시·압축 목록과 첫 렌더링이 포함됩니다. 이어서 현재 화면의 모든 타일이 완성됐는지 별도로 확인합니다. 페이지 이동과 확대·배치·반전 30회를 검사하고, 문서를 닫고 다시 열어 저장된 페이지 키가 유지되는지 10회 검사합니다. 핀치·두 번 탭·방향별 스와이프는 일반 회귀 검사에서 검증합니다.

조작 묶음은 배치·반전 설정 변경, 임의 페이지 이동과 해당 화면의 전체 타일 완료를 포함합니다. 재열기는 복사 또는 캐시 검증부터 첫 타일까지이며 P95는 nearest-rank 방식입니다. 특히 7Z의 임의 이동은 앞선 스트림을 읽는 비용으로 수십 초 걸리는 경우가 있습니다. 이때 준비 표시와 취소가 제공됩니다. ZIP이 빠른 임의 이동에 더 적합합니다.

통과 기준은 앱/작업 프로세스/합산 PSS 각각 384/512/768MiB, 초기 안정 구간 대비 후반 앱 PSS 증가 96MiB, FD 증가 24개 이하입니다. 호스트에서 약 2초 간격으로 메모리를 조회하며 각 프로세스 조회는 순차적입니다. 화면 타일 완성 제한은 90초, 시나리오 전체 제한은 20분입니다. 각 화면의 타일 캐시 한도와 렌더링 실패 0건, 압축 원본 SHA-256 보존을 함께 검사했습니다.

## 검사에서 수정한 문제

Android 16의 첫 1GiB 재열기 검사에서 cacheDir 안의 압축 캐시가 사라져 ENOENT가 발생했습니다. 대용량 이미지 저장소를 noBackupFilesDir 안에서 직접 관리하고, 캐시 검증 도중 파일이 사라져도 원본에서 다시 준비하도록 수정했습니다. 문서를 닫을 때 비활성 캐시를 512MiB 이하로 정리하므로 1GiB 압축은 재열기마다 다시 복사됩니다. 일반 설정의 읽기 캐시 정리에서도 이 저장소를 정리합니다. 누락·손상 캐시 복구와 취소 후 임시 파일 정리를 회귀 검사에 포함했습니다.

수정 전 실패 로그도 증거에 보존했습니다. 초기 API 36 측정 중 에뮬레이터가 종료된 실행은 결과에서 제외했고, 재시작한 환경에서 최종 전체 시나리오를 다시 실행했습니다. 위 표는 최종 코드의 통과 결과만 사용합니다.

## 기능·빌드 확인

부하 검사 이후 이미지가 시스템 영역에 그려지지 않도록 AndroidView의 화면 영역 제한을 추가했습니다. 이미지 소스·디코딩·캐시 코드는 바뀌지 않았습니다. 최종 release 빌드의 실제 화면을 별도로 확인했으며, 측정 APK 해시는 각 manifest에, 최종 release 해시는 checks.json에 기록했습니다.

- ZIP/CBZ, RAR4/5/CBR, 솔리드 7Z/CB7 열기와 자연 정렬, JPG/PNG/WebP/BMP/GIF 렌더링, EXIF 8방향, 반전 RGB·투명도 보존.
- 암호·손상·빈 압축 안내, 잘못된 이미지 건너뛰기, 분할 RAR 헤더 거절, 경로 탈출·메타데이터 제외.
- 세로/좌우·두 쪽·방향 변경, 확대 후 이동과 설정 변경 위치 보존, 마지막 페이지 렌더링, 독립 이미지 설정 초기화.
- Room 2→3 이관, 기존 PDF 기록 보존, 오래된 세션 저장 거절, 책갈피 중복·기록 삭제.
- 실제 SAF 경로의 이미지 폴더 및 압축파일 열기, 반전, 전체 화면 설정, 썸네일 이동, 책갈피, 앱 프로세스 재시작 후 이어 읽기.
- 최종 release에서 200% 확대한 4페이지를 가로 화면으로 회전한 뒤 세로로 되돌려 페이지·확대율 보존 확인. 시스템 표시 영역을 침범하지 않는 최종 화면과 설치 APK 해시도 확인.

TXT 코어 9개와 앱 단위 테스트 23개가 통과했습니다. Lint는 오류 0개, 경고 46개입니다. 경고에는 기존 의존성 업데이트·KTX 권장·그리기 중 할당·접근성 항목 등이 남아 있습니다. 최적화 release APK는 48.20MiB이며, ARM64/x86_64 네이티브 라이브러리 10개의 LOAD 정렬과 APK ZIP의 16KB 정렬을 확인했습니다. 16KB 페이지 크기 OS에서의 실행 시험은 별도입니다.
