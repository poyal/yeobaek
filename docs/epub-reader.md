# EPUB 읽기

2026-10-17, v0.4.0. [릴리즈 안내](releases/v0.4.0.md) · [실행 증거와 미검증 범위](releases/0.4.0-verification.md)

## 파일과 조작

- 일반 EPUB 2·3과 DRM 없는 구매 EPUB을 로컬 파일로 엽니다. 연결한 폴더에서 선택하거나 파일 앱의 **다른 앱으로 열기 → 여백**을 사용합니다.
- 일반 본문은 기본 **장별 세로 스크롤**입니다. 장 경계에서는 이전·다음 장 버튼 또는 좌우 스와이프로 이동합니다. 설정에서 **페이지 넘김**을 선택할 수 있습니다.
- 고정 지면 책은 한 페이지씩 넘기며 두 손가락으로 확대·이동합니다. 다시 열면 같은 페이지를 화면에 맞춰 표시합니다. 세로 연속·두 쪽 펼침은 제공하지 않습니다.
- 목차, 본문 검색, 텍스트 선택·복사, 책갈피, 이어 읽기를 제공합니다. 이미지로만 된 본문에는 검색·선택할 텍스트가 없으며 OCR은 제공하지 않습니다.
- 내부 링크와 각주 이동 후 **이전 위치**로 돌아옵니다. 검색 결과를 누른 뒤 검색 패널의 **원래 위치로**를 사용할 수 있습니다. 외부 웹 링크를 누르면 설치된 브라우저로 엽니다.
- EPUB 설정은 설정 첫 화면에서 바로 엽니다. 공통·이 폴더·이 책 범위에 글꼴·크기·읽기 방식·본문 색상을 저장합니다. **원본 서식**을 끄면 줄 간격과 여백도 조절합니다. 고정 지면에서는 원본 본문을 유지하고 바깥 배경만 조절합니다.

DRM 해제, 서점 로그인·다운로드, ACSM, LCP, 오디오·비디오·미디어 오버레이, 책에 포함된 스크립트와 외부 웹 리소스는 지원 범위 밖입니다. EPUB 표준 글꼴 난독화는 본문 DRM과 구별하여 허용합니다. DRM 없는 구매 파일도 제작 방식과 원본 상태에 따라 확인이 필요합니다.

## 저장과 구조

- 엔진은 [Readium Kotlin 3.1.2](https://github.com/readium/kotlin-toolkit/tree/3.1.2)의 shared·streamer·navigator입니다. 기존 TXT·PDF·이미지 엔진은 유지합니다.
- `EpubStore`가 원본 URI를 취소 가능한 스트림으로 복사하며 SHA-256을 계산합니다. ZIP·보호 정보를 검사한 다음 publication을 열고, 원본 버전이 같은 읽기 위치를 복원합니다. 원본이 바뀌면 처음부터 열기·취소를 안내하고 이전 기록은 유지합니다.
- 책을 열 때 캐시를 512MiB 기준으로 최근 사용 순서에 따라 정리하며 열려 있는 책은 제외합니다. 책 한 권이 이 기준보다 크면 보관하고 다음 책을 열 때 다시 정리합니다. 다시 열 때 원본 접근 권한과 원본 변경 여부를 확인합니다. 표지는 실제 열었던 EPUB에서만 만듭니다.
- `EpubHostFragment`가 Readium 화면 수명을 담당하고, `EpubReaderController`가 현재 위치·검색·책갈피와 저장을 담당합니다. 툴바의 실제 높이를 측정한 다음 본문을 배치하며, WebView가 준비되기 전에는 초기 위치로 저장하지 않습니다. 설정 화면으로 전환할 때 준비 상태를 즉시 해제하고 닫힌 렌더러의 늦은 JavaScript 응답을 무시합니다.
- 위치는 Readium Locator JSON과 원본 해시를 함께 보관합니다. 일반 본문은 CSS 선택자·본문 인용·진행률을 담고, 고정 지면은 페이지 리소스를 기준으로 복원합니다. 글자 크기나 읽기 방식이 달라지면 저장한 문단이 포함된 화면으로 이동하므로 화면 맨 위 문단은 달라질 수 있습니다.
- Room 4→5 이전으로 `epub_positions`, `epub_bookmarks`를 추가합니다. 기존 형식의 테이블과 기록을 보존하며 세션·저장 순서가 오래된 쓰기를 차단합니다.
- 독서 기록 백업은 버전 2를 내보내고 버전 1·2를 가져옵니다. EPUB 위치·책갈피·설정을 포함하며 책 원본과 읽기 캐시는 포함하지 않습니다.
- 검색은 전체 결과를 임시 파일에 저장하고 화면에는 100개씩 읽습니다. 검색 취소·책 닫기·재실행 시 임시 자료를 정리합니다.
- 책 HTML의 스크립트·이벤트 속성을 제거하고 CSP로 로컬 리소스와 Readium의 스크립트만 허용합니다. 원본 파일은 수정하지 않습니다.

## 검증

자동 검사에는 직접 만든 한글·영문 EPUB 2/3, 고정 지면, 글꼴 난독화 메타데이터, 본문 암호화, 손상 ZIP을 사용합니다. 실제 구매 도서는 제공받지 않았습니다.

`EpubEngineTest`, `EpubPersistenceTest`, `EpubReaderTest`, `EpubSettingsTest`가 형식 판별, 검색, DRM 구분, DB 이전, 백업, 설정 적용, 위치 복원과 고정 지면 이동을 검사합니다. `EpubSoakTest`는 `epubSoakSeconds` 인수를 주었을 때만 실행하며 40장·6,000문단 책에서 이동·검색·설정 변경·다시 열기를 반복하고 앱 내부 `files/epub-soak.json`에 PSS·파일 디스크립터 수를 기록합니다.

`EpubJourneyTest`는 최적화된 release APK를 외부 테스트 앱에서 조작합니다. 실제 폴더 권한, 외부 앱 열기·권한 회수, 검색·책갈피·설정, PID 교체 후 복원, 회전·큰 글씨, 백업 내보내기·빈 앱 가져오기, 원본 변경 취소와 옛 책갈피 보존을 검사합니다. 실행 수치·산출물 해시·API별 결과는 [0.4.0 검증 기록](releases/0.4.0-verification.md)에 모읍니다. 합성 책 검사는 모든 출판사의 구매 EPUB 호환성을 보장하지 않으며, 실물 기기와 TalkBack 발화 검사는 별도입니다.
