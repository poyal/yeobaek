# 여백 v0.1.0

여백의 첫 공개 APK입니다. Android 11 이상에서 기기의 TXT 파일을 읽고, 읽던 위치와 책갈피를 이어갈 수 있습니다.

## 주요 기능

- 시작 폴더 연결과 하위 폴더 탐색, 최근 읽기, 앱 재실행 시 이어 읽기
- 연속 스크롤, 본문 검색, 책갈피, 읽기 위치 이동
- 명조·고딕, 글자 크기·행간·여백, 라이트·세피아·다크 본문
- UTF-8·UTF-16·CP949·EUC-KR 인코딩과 미리보기
- 원본 이동·변경 시 기록 복구와 파일 재연결
- 앱 정보·문의, GitHub 업데이트 확인, APK 다운로드·검증·설치 안내

검색 결과 100개 경계를 넘을 때 잘못된 위치로 이동하던 문제와 불완전한 캐시 메타데이터의 복구 오류를 수정했습니다. 폴더 복귀 시 외부 변경을 새로 읽고, 읽기 위치 이동과 검색 취소 시 지난 요청이 새 화면을 덮지 않게 보강했습니다.

## 설치와 업데이트

첨부된 `yeobaek-0.1.0.apk`를 설치합니다. SHA-256은 `yeobaek-0.1.0.sha256`에서 확인할 수 있습니다. 이후 버전은 **설정 → 업데이트**에서 확인합니다. 앱을 삭제하지 않고 같은 서명의 새 APK로 업데이트해야 독서 기록이 유지됩니다.

이 APK는 이번 Windows 환경에서 준비한 여백 전용 키로 서명했습니다. 이전 문서의 별도 로컬 검증 APK와는 서명이 다릅니다. 그 APK를 사용 중이라면 삭제로 기록을 잃지 않도록 원래 서명 키를 사용하는 빌드가 필요합니다.

## 지원 범위와 확인 결과

TXT 원본은 최대 100MiB이며 PDF·EPUB·이미지 뷰어는 포함하지 않습니다. 책과 독서 기록은 기기에 저장하며 업데이트 확인·다운로드에 본문이나 기록을 전송하지 않습니다.

Windows에서 JVM 검사 26개와 Android 16 전용 에뮬레이터 검사 18개를 통과했습니다. 기능·복구·앱 정보·업데이트·대용량 TXT와 125개 화면을 확인했으며 Lint 오류는 0개입니다. 실제 기기의 60/120Hz 성능, 발열·배터리, TalkBack 인수는 완료하지 않았습니다. 과거 에뮬레이터의 프레임 목표 미달을 이번 기능 검사 통과로 대체하지 않습니다.

검사별 실행 결과, APK 해시와 화면은 [검증 기록](https://github.com/poyal/yeobaek/blob/v0.1.0/docs/releases/0.1.0-verification.md)에서 확인할 수 있습니다. 사용법은 [사용자 안내](https://github.com/poyal/yeobaek/blob/v0.1.0/README.md), 문제 신고는 [GitHub Issues](https://github.com/poyal/yeobaek/issues)를 이용해 주세요.
