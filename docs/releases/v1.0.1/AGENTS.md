첫 release 증분 컴파일에서 기존 캐시의 참조 오류가 발생해 앱·코어 빌드 산출물을 정리하고 전체 컴파일했습니다. 최종 JVM 검사는 새로 실행했습니다. 첫 밝은 화면 E2E는 팝업 항목의 테스트 ID가 UIAutomator에 노출되지 않아 실패했으며, 실제 표시 문구로 선택하는 외부 검사 코드로 수정한 후 밝게/어둡게 전체를 다시 통과했습니다. 복구 검사는 세로 목록의 화면 밖 폴더와 200% 글씨 설정 아래쪽 버튼을 탐색하지 않아 실패했으며, 두 위치의 스크롤 탐색을 보완한 최종 실행으로 대체했습니다. EPUB의 기존 페이지 문자열 비교도 진행률이 추가된 표시와 맞지 않아 실패했으며, 페이지 번호 부분을 정확히 비교하도록 보완했습니다. 고정 지면은 마지막 페이지 도달 시 완독 안내가 나오므로 안내를 닫은 뒤 3/3·100%, 재열기 시 완료 유지·안내 중복 없음, 이전 페이지에서 완료 해제까지 확인하도록 갱신하고 두 테마 전체를 다시 실행했습니다. Android 16 파일 선택기의 늦은 이전 폴더 복원도 확인해, 전용 AVD의 새 앱 시나리오에서는 파일 선택기 이력도 초기화했습니다. 실패 실행을 최종 통과 수에 포함하지 않았습니다.

TXT 연속 읽기는 최초 검사 APK, TXT 실제 UI·복원·앱 정보는 팝업 탐색 보완 APK, 복구·용량·반복은 스크롤 탐색 보완 APK, EPUB은 페이지 표시와 완독 시나리오까지 반영한 최종 검사 APK로 실행했습니다. 각 실행의 APK 해시를 구분했습니다. 앱 소스와 배포 APK는 유지했으며, 검사 코드 수정이 영향을 주는 시나리오를 다시 실행했습니다.

추가 release UI 확인에서 두 번의 개별 ADB 탭 명령으로 200% 확대를 만들려던 시도는 기대한 확대를 재현하지 못했습니다. 이 입력 방식의 시간 간격을 보장하지 못하므로 해당 결과를 통과로 집계하지 않았습니다. 추가 확인 범위는 확대 설정의 기본값·변경 보존, 초기화 버튼 접근·실행, 메뉴 표시 방식과 목록으로 한정했습니다. 일부만 보이는 이미지 설정 스위치를 누르던 준비 코드도 화면 안에 완전히 들어온 뒤 누르도록 수정했습니다. 두 번 탭·핀치·스크롤 제스처 자체는 Android 11·16의 debug 통합 검사에서 검증했으며, release의 두 번 탭 확대 재현을 확인한 것으로 기록하지 않습니다.

## 성능과 장시간 읽기

50MiB TXT를 1,800,461ms 동안 양방향으로 1,947회 스와이프했습니다. 각 입력 후 정지를 기다리고 본문 블록의 이동 방향을 대조했습니다. PID `3658`가 유지됐으며 오류·화면 이탈·프로세스 재시작을 검출하지 않았습니다. PSS 8개 표본은 70,589~92,541KiB였습니다.

종료 시 gfxinfo 프레임 시간 P50/P95/P99는 9/27/48ms입니다. 1MiB TXT 100회 재열기의 UI 자동화 경과 시간 P50/P95/P99는 1409/1989/2817ms입니다. 연속 읽기는 다른 전용 AVD의 UI 검사 및 일부 외부 검사 APK 빌드와 동시에 실행했습니다. 에뮬레이터의 프레임 시간과 UI 대기를 포함한 열기 시간이며, 실물 기기의 frameOverrunMs·발열·배터리 성능 목표를 통과한 것으로 해석하지 않습니다.
