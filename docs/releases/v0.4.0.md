# 여백 v0.4.0

일반 EPUB과 DRM 없는 구매 EPUB을 읽을 수 있습니다. 형식별 설정을 설정 첫 화면으로 옮기고, 모든 설정 화면에 같은 카드 배경과 간격을 적용했습니다.

## EPUB 읽기

- EPUB 2·3의 일반 본문은 장별 세로 스크롤로 읽으며 페이지 넘김으로 바꿀 수 있습니다. 이전·다음 버튼과 좌우 스와이프로 장을 이동합니다.
- 고정 지면 책은 한 페이지씩 넘기고 두 손가락으로 확대·이동합니다. 다시 열면 같은 페이지를 화면에 맞춰 표시합니다.
- 목차·본문 검색·선택과 복사·책갈피·이어 읽기를 제공합니다. 내부 링크와 검색 결과에서 읽던 자리로 돌아갈 수 있습니다.
- 공통·이 폴더·이 책 범위로 글꼴·크기·본문 색상·읽기 방식을 저장합니다. 원본 서식을 끄면 줄 간격·여백도 조절합니다.
- 폴더 목록과 외부 앱의 **다른 앱으로 열기**를 지원합니다. 원본이 바뀌면 처음부터 열기·취소를 안내하며 이전 기록을 유지합니다.

## 설정과 기록

- 설정 첫 화면에서 TXT·EPUB·PDF·이미지 설정을 바로 엽니다. 일반 설정·백업·저장 공간·앱 정보·업데이트 화면에도 같은 카드 디자인을 적용했습니다.
- 백업 v2에 EPUB 위치·책갈피·설정을 포함합니다. 기존 v1 백업도 가져올 수 있습니다. 원본 책과 OS 파일 접근 권한은 별도로 보관·연결해야 합니다.
- TXT 스크롤을 멈추는 짧은 터치 뒤 실제 드래그 없이 새 플링이 발생하는 경우를 차단했습니다. 사용자 진단 로그를 바탕으로 보완했으며 해당 갤럭시 실기기의 재확인은 남아 있습니다.

## 업데이트와 범위

Android 11 이상, 버전 `0.4.0` / `versionCode 4`입니다. 기존 공개 버전과 같은 서명 키를 사용합니다. 앱을 삭제하지 말고 기존 앱 위에 설치하세요. v0.3.0에서 DB 4→5 이전, TXT·PDF·이미지 기록·설정·원본·폴더 접근 권한 보존을 확인했습니다.

DRM 해제·서점 로그인·ACSM/LCP·오디오/비디오·책의 스크립트·외부 웹 리소스는 지원하지 않습니다. 이미지로만 된 EPUB은 검색·선택할 텍스트가 없을 수 있습니다. 실제 구매 파일은 제공받지 않아 합성 EPUB으로 검사했습니다. 실물 기기 성능·TalkBack 발화·16KiB 페이지 OS는 별도 검증이 필요합니다.

Android 11 AOSP 에뮬레이터에서는 시스템 파일 선택기가 이전 폴더를 복원할 때 선택 버튼이 나타나지 않는 경우가 있었습니다. 해당 상태의 실패는 검증 문서에 보관했으며, 새 앱 복원 E2E는 파일 선택기 기록도 초기화하여 수행합니다. 외부 파일 앱의 **다른 앱으로 열기**도 사용할 수 있습니다.

JVM 56개, Android 11·16 통합 각 48개, 최종 release E2E 23개가 통과했습니다. EPUB 30분 반복은 1,139회 통과했고, 기존 버전 덮어 설치와 빈 앱 백업 복원도 확인했습니다. E2E의 OS 선택기 초기화 조건과 알려진 제약은 검증 문서에 구분했습니다.
