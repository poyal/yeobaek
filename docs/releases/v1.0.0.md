# 여백 v1.0.0

TXT·EPUB·PDF·이미지·만화 압축파일을 읽고, 읽던 위치와 책갈피·설정을 기기에 보관합니다. 이번 버전은 TXT에서 스와이프 후 멈췄다가 손을 뗄 때 발생할 수 있는 역방향 관성 스크롤 방어를 보완합니다.

## TXT 스크롤 보완

- 손가락을 거의 움직이지 않고 관성 스크롤을 멈추는 터치와, 스와이프한 뒤 잠시 멈췄다가 손을 떼는 동작을 모두 확인합니다.
- 손을 떼기 직전의 움직임을 확인해 잘못된 관성 스크롤을 차단합니다. 실제 양방향 스와이프와 방향 전환은 유지합니다.
- 입력 처리가 지연돼도 방어 조건이 미리 만료되지 않도록 보완했습니다.
- 진단 로그에 손을 떼기 직전 이동 범위와 관찰 시간을 추가했습니다. 책 본문·제목·원본 URI는 기록하지 않습니다.

사용자 로그에서 확인한 사례를 바탕으로 수정했습니다. 해당 갤럭시 실기기에서 수정 효과를 다시 확인하는 작업은 남아 있으며, 에뮬레이터의 좌표 재생 검사를 실기기 확인으로 간주하지 않습니다.

## 설치와 기록

Android 11 이상, 버전 `1.0.0` / `versionCode 6`입니다. 기존 공개 버전과 같은 서명 키를 사용합니다. **앱을 삭제하지 말고 기존 앱 위에 설치하세요.** DB 스키마와 독서 기록 형식은 0.4.0과 같습니다.

TXT·DRM 없는 EPUB·PDF·이미지·CBZ/ZIP 읽기, 책·폴더별 설정, 검색·책갈피·수동 백업을 제공합니다. EPUB의 서점 로그인·DRM 해제·ACSM/LCP, OCR, 클라우드 동기화는 지원하지 않습니다.
