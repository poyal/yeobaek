이번 후보에서 성공한 자동 검사는 단위 38개와 Android 계측 실행 50개(debug 39 / release E2E 11)입니다. 별도로 첫 복구 실행의 setup 실패 1회를 아래에 기록합니다. 수동 화면 검수·완독 흐름과 과거 부하 검사는 이 숫자에 합산하지 않았습니다.

복구 첫 실행의 파일 재연결 항목은 앱 본문에 들어가기 전 OS 폴더 권한 팝업에서 `StaleObjectException`이 발생했습니다. 같은 APK·같은 검사 코드로 해당 항목을 다시 실행해 통과했습니다. 첫 실행 전체를 PASS로 바꾸지 않았으며 [실행별 원시 결과](0.2.0-evidence/runs.json)에 실패와 재검사를 모두 남겼습니다.

완독 흐름은 이미지 폴더 → 다음 이미지 폴더 → TXT → PDF → CBZ 순서입니다. 빈 폴더 건너뛰기, 마지막 항목에서 다음 버튼 숨김, 나가기로 원래 폴더 복귀, 뒤로 닫은 안내의 반복 방지, 최근 읽기로 다시 연 PDF에서 원래 폴더의 다음 항목 찾기를 확인했습니다. [실제 안내 화면](0.2.0-evidence/reading-end/04-next-archive.png)을 보존했습니다.

API 30 E2E는 이 작업에서 새로 만든 `yeobaek-release-api30`에서만 앱 데이터를 초기화했습니다. 기존 API 36의 앱 데이터는 삭제하지 않았습니다. 문서·이미지·압축파일은 합성 자료입니다.

재현용 자료 해시는 [TXT 1,021개](0.2.0-evidence/txt-fixtures.json), [완독·메뉴 검수용 자료](0.2.0-evidence/reading-end-fixtures.json)에 있습니다. API 30의 라이트·다크 검사는 단순 Activity 재생성과 별도로 `am kill` 전후 PID가 달라진 것을 기록했습니다. [라이트 종료 기록](0.2.0-evidence/e2e-light/process-death.txt), [다크 종료 기록](0.2.0-evidence/e2e-dark/process-death.txt)을 확인할 수 있습니다. OS 메모리 부족 종료를 재현한 것은 아닙니다.

대표 재현 명령은 다음과 같습니다. 데이터 초기화가 있는 E2E는 합성 자료만 있는 별도 `yeobaek-*` AVD에서 실행해야 합니다.

```sh
scripts/build.sh :app:testDebugUnitTest :core:txt:test :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease :e2e:assembleDebug :app:lintDebug
python3 scripts/verify-device.py --serial emulator-5582 --suite e2e --variant release --theme LIGHT
python3 scripts/verify-device.py --serial emulator-5582 --suite recovery --variant release
python3 scripts/verify-device.py --serial emulator-5582 --suite e2e --variant release --theme DARK
python3 scripts/verify-device.py --serial emulator-5582 --suite restore --variant release
python3 scripts/verify-device.py --serial emulator-5582 --suite about --variant release
```

복원 검사는 다크 읽기 시나리오가 남긴 시작 폴더·위치·책갈피·글자 크기·테마를 검사합니다. 같은 APK 덮어 설치 후 한 번, 재부팅 후 한 번 실행했습니다. 공개 v0.1.0에서의 업데이트 검사를 대신하지 않습니다.

### Mac 대용량 결과와 검사 범위

[PDF 100/300MiB 부하](../pdf-load-verification.md)와 [이미지 1GiB·10,000장·RAR/7Z 부하](../image-load-verification.md)는 같은 날 수행한 **이전 debug APK**의 결과입니다. 각 문서의 해시·원시 결과를 유지하며 이번 `0.2.0` release APK의 새 측정으로 취급하지 않습니다. 마지막 변경은 공통 메뉴·홈 아이콘·버전이며, 이번에는 엔진·네이티브 화면·영속 기록·완독 회귀와 최적화 release의 실제 화면 흐름을 검사합니다.

실물 기기의 성능·발열·배터리, 실제 TalkBack 발화, 16KiB 페이지 OS, 제조사·클라우드 문서 공급자, 30분 연속 읽기·성능 백분위 재측정은 이번 후보에서 **NOT_RUN**입니다. 과거 성능 측정의 한계도 그대로 유지합니다. 공개 게시·공개 파일 재다운로드 검사는 사용자에게 인계합니다.
