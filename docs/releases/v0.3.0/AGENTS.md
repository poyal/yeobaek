## 공개 v0.2.0 → v0.3.0 업데이트

새 전용 AVD `yeobaek-release-030`에 실제 공개 v0.2.0 APK를 설치하고, TXT·PDF·만화의 위치·책갈피·형식별 설정, 다크 테마, TXT 글자 크기 19와 이어 읽기 세션을 저장했습니다. 사용자가 수동 테스트 중인 `yeobaek-api36`은 초기화하거나 조작하지 않았습니다.

**PASS:** 삭제 없이 최종 APK를 덮어 설치한 뒤 Room 3→4 이전을 확인했습니다. 기존 `books`, `positions`, `bookmarks`, `session`, `pdf_positions`, `pdf_bookmarks`, `image_positions`, `image_bookmarks`의 행 수와 기존 열 값이 모두 동일합니다. 이미지 위치·책갈피에 추가한 `segment`는 기존 기록에서 `-1`입니다. 앱/TXT/PDF/이미지 설정 파일, 영속 SAF 권한 파일과 외부 TXT 원본 해시도 동일합니다.

실제 화면에서 이어 읽기 확인, 50% 이후 TXT 위치, 책갈피, 크기 19와 다크 테마를 확인했습니다. 결과·이전·이관 직후·이어 읽기·설정.

## 개발 단계의 별도 증거와 미검증 범위

대용량 TXT의 파일 탭부터 본문 준비까지 측정한 단일 실행 값은 1MiB 867ms, 10MiB 954ms, 50MiB 1,748ms, 100MiB 2,337ms입니다. 각 1회 표본이며 디스크의 OS 캐시를 비우지 않았습니다. 실기기 지연이나 P95 성능 수치로 해석하지 않습니다.

앞서 수행한 50MiB TXT **30분 0.364초 / 1,980회** 스크롤과 변경 화면 13장은 개발 HTML 보고서에 있습니다. 해당 검사는 별도 debug APK에서 수행했으며, 이 릴리즈 APK의 30분 검사로 합산하지 않습니다. APK 해시와 메모리 표본은 개발 검증 메타데이터에 있습니다.

이번 릴리즈의 갤럭시 실기기 터치 재현·프레임 성능·발열·배터리, TalkBack 실제 발화, Android 11 실행, 16KiB 페이지 OS, 제조사·클라우드 문서 공급자 및 프레임 백분위 재측정은 **NOT_RUN**입니다. 최소 지원 API와 검사한 OS를 구분하며, 과거 릴리즈의 통과 결과를 이번 APK의 결과로 복사하지 않습니다.
