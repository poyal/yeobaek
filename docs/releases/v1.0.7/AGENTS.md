## 이미지 스크롤과 확대·축소

아래 성능 비교에는 버전 번호를 올리기 전 같은 뷰어 구현을 담은 서명 release APK(`9cf7d99e58f9046bfd827e5bc5fb785a2864ee00d32ba84fc47e91aeca145489`)와 공식 v1.0.6(`4dc05f31c7938a274fab4c9c90804643a93650bb592198a7ddc963a4ba21326b`)을 사용했습니다. Android 16 x86_64 전용 AVD, 720 × 1600 px, 60 Hz, speed 컴파일 조건에서 같은 합성 이미지 24장을 CBZ와 폴더로 각각 열었습니다. 화면 녹화와 프레임 계측은 따로 실행했습니다.

- 이전 버전에서는 두 녹화 모두 이미지 위로 준비 안내가 겹쳤습니다. 변경 후 CBZ 779프레임과 폴더 787프레임에서 이미지 위의 준비 문구와 화면 중앙이 빈 프레임은 각각 0개였습니다.
- UIAutomator로 빠르게 확대·축소한 두 실행에서 유효 표본을 합산했습니다. 프레임이 표시 기한을 넘긴 비율은 CBZ에서 4.01% → 16.38%, 폴더에서 4.05% → 16.14%였습니다. 별도로 16 ms 간격으로 일정하게 확대·축소했을 때 프레임 시간 P95는 CBZ 21 → 18 ms, 폴더 18 → 18 ms였습니다.
- 버전 변경 전 debug 기기 검사 17개와 부하 사례 2개가 통과했습니다. 큰 이미지 압축파일과 10,000장 폴더에서 각각 30회 조작하고 10회 다시 열었습니다. 두 사례 모두 파일 디스크립터 순증가는 0개였습니다.

## 최종 APK의 기기 검사

Android 11(API 30)과 Android 16(API 36) AOSP x86_64 전용 AVD에서 같은 서명 APK를 설치했습니다. 기본 화면은 720 × 1600 px, 320 dpi입니다.

- Android 11 밝은 테마에서 예상 메서드 8개가 통과했습니다. TXT 검색·인코딩·회전·설정, EPUB 검색·목차·고정 지면·원본 변경·권한 상실 복구, 실제 폴더 선택기 취소와 재연결, 1,000개 파일 탐색, 큰 글씨와 키보드 검색, 공통·폴더·책 설정 상속과 개별 초기화를 확인했습니다.
- Android 11에서 실제 프로세스 종료 후 TXT PID가 2367 → 2460으로 바뀌고 읽기 위치가 복원됐습니다. EPUB도 PID가 3536 → 3758로 바뀐 뒤 진행률 33%, 3758 → 4035로 바뀐 뒤 64%를 복원했습니다.
- Android 16 어두운 테마에서 만화 썸네일·펼침면·여백 자르기, 압축 형식과 이미지 폴더 탐색, PDF 선택·확대·회전, 네 형식 연속 완독 여정이 통과했습니다. 만화는 PID 2718 → 2871로 바뀐 뒤 3쪽 오른쪽과 화면 위치를, PDF는 PID 3505 → 3655로 바뀐 뒤 읽기 위치를 복원했습니다.
- 좁은 화면 검사는 640 × 1280 px, 글씨 200%에서 외부 검사 도구가 시스템 폴더 선택기의 합성 폴더를 찾지 못해 중단됐습니다. 폭 320 dp와 글씨 200%를 유지하고 기기 기본 세로 길이로 돌린 640 × 1600 px에서 TXT → PDF → 만화 → 고정 지면 EPUB 완독 및 폴더 복귀가 통과했습니다. 성공한 Android 11·16 여정에서 누락·생략·중복 메서드는 0개였습니다.
