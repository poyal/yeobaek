- 앱 소스 커밋은 `ea0d8597b348bbc18e6895f6ecd94eab121d2488`입니다. 테스트한 최적화 release APK를 `.tools/releases/1.0.5/`에 고정했습니다.

- `yeobaek-1.0.5.sha256`은 84바이트이며 SHA-256은 `745fc9e3ab9f45f13874d2c7915196aaaa7088952b2d9f3480bb073728334526`입니다.
- 공개 v1.0.4와 후보에서 APK v2 서명과 동일한 인증서 SHA-256 `5ad108f18a7477f91a281b4feb26301a14247e59440607c5f7710582ac92fd48`을 확인했습니다. 후보는 `zipalign -c -P 16 4` 검사를 통과했습니다.

## 단위 검사와 개발 중 기기 검사

- release 단위 검사에서 앱 64개와 TXT 코어 9개가 통과했습니다. 실패·오류·생략은 0개였습니다. 호스트 검사 16개가 통과했고, release Lint 결과는 오류 0개와 경고 62개입니다.
- 버전 갱신 전 같은 앱 변경을 대상으로 Android 16 x86_64 전용 AVD에서 debug 기기 검사 18개를 실행했습니다. 첫 실행의 EPUB 위치 복원 1건은 단독 재실행과 18개 전체 재실행에서 통과했습니다. 일반 EPUB 목차 제목과 본문 이동, 완독 창 동작을 확인했습니다.
- 최근 읽기는 Room에 2015년 열람 시각의 책 1,001권을 넣고, 가장 오래된 기록의 유지, 같은 책을 다시 열었을 때의 순서와 권수, 한 권 삭제 후 나머지 기록의 일치를 확인했습니다.
- 공개 v1.0.4와 변경 후 debug 앱에서 같은 합성 책으로 화면 26종을 촬영했습니다. 가로 320dp와 시스템 글자 배율 2.0에서 일반 EPUB 상단과 완독 창을 확인했습니다. 이 비교 촬영은 정식 서명 APK의 기기 검사와 별도로 수행했습니다.

## 공개판 덮어 설치와 복원

Android 16 x86_64 전용 AVD에서 공식 v1.0.4 APK의 SHA-256 `48675c75e6fce7edfc57fff7bc552b2964aacaf88c0991f9a62f80c9b6434c08`을 확인하고 네 형식의 책을 열어 기록을 만들었습니다. v1.0.5를 덮어 설치한 직후, 첫 실행 전의 Room 스키마 5와 전체 테이블, DataStore 파일 세 개의 해시, 영속 SAF 권한이 설치 전과 일치했습니다.

업데이트 후와 AVD를 완전히 껐다 켠 뒤에 각각 시작 폴더와 이어 읽기를 확인했습니다. TXT의 60.7% 위치와 책별 글자 크기 19, PDF 40쪽, 만화 9쪽, EPUB 두 번째 본문, 네 형식의 책갈피, 어두운 테마가 복원됐습니다. 외부 원본 44개 해시와 책 ID·인코딩·본문 버전·책갈피도 일치했습니다. 재시작 전 게스트 파일 시스템을 동기화했고, 부팅 ID가 `526e6d82-6b62-4728-b0b2-3dea5dba94ed`에서 `259a4048-7936-4df9-8188-c68feeb63a53`으로 바뀌었습니다.

첫 실행은 재부팅 직후 Android System UI가 응답 대화상자를 표시해 마지막 앱 실행 단계를 완료하지 못했습니다. 전용 AVD의 시스템 대화상자를 처리한 뒤 공개판 기록 생성부터 재부팅 후 전체 대조까지 다시 수행해 통과했습니다.

## 서명된 APK의 기기 검사

Android 11(API 30)과 Android 16(API 36)의 x86_64 전용 AVD에 같은 APK를 설치했습니다. 두 환경의 기본 화면은 720 × 1600 px, 밀도는 320 dpi입니다.

- Android 11 밝은 테마에서 TXT 읽기·검색·인코딩·설정 왕복 2개 및 EPUB 목차·내부 링크·검색 복귀·책갈피·설정·백업·원본 변경·접근 권한 복구 3개가 통과했습니다. TXT 프로세스가 `2826`에서 `2923`으로, EPUB 프로세스가 `4029`에서 `4248`로 교체됐습니다. EPUB은 종료 전후 진행률 33%를 복원했습니다. TXT는 별도로 복원 후 가로 회전도 검사했습니다.
- Android 11 어두운 테마에서 파일 1,000개 목록을 탐색하고, 시스템 글씨 200%에서 TXT 설정과 실제 키보드를 사용해 본문 검색을 완료했습니다.
- Android 11의 실제 폴더 선택기에서 취소·재연결, 빈 폴더 탐색, 앱 종료 후 시작 폴더 복원을 확인했습니다. 최초 검사와 단독 재검사는 목록 전환 직후 이전 폴더의 행을 읽었습니다. 당시 캡처에는 빈 폴더가 정상 표시됐습니다. 빈 상태 안내가 나타난 뒤 목록을 검사하도록 외부 테스트만 수정한 `26979b627f6bfda69d44b0b18eb06046b30409a9`에서 같은 앱 APK로 통과했습니다. 외부 검사 APK를 다시 설치할 때 서명 설정이 달라 설치가 거부된 시도는 실행 횟수에서 제외했습니다. 원래 검사 서명 설정으로 다시 빌드해 실행했습니다.
- Android 16 어두운 테마에서는 완독 창으로 TXT → PDF → CBZ → 고정 지면 EPUB을 열었습니다. 폴더의 마지막 책에서 **폴더로 돌아가기**만 표시되고 원래 폴더로 복귀하는지 확인했습니다. 이후 가로 320dp, 시스템 글씨 200%로 고정 지면 EPUB을 다시 열어 마지막 페이지 번호와 진행률을 확인했습니다.
- 덮어 설치 검사와 별개로 최종 release 사용자 여정은 Android 11에서 7개, Android 16에서 2개가 통과했습니다. 각 성공 실행에서 예상 메서드 이름과 실제 목록을 대조했고 누락·생략·중복은 0개였습니다.

Android 16의 밝은 테마에서 합성 TXT 1·10·50·100MiB를 열어 앞뒤 스크롤 및 80% 위치 이동을 검사했습니다. 줄바꿈 없는 1MiB 본문, 빈 줄이 많은 문서, 결합문자도 읽었고 101MiB 파일에서 용량 제한 안내를 확인했습니다. 다음은 한 번의 여정에서 기록한 열기 시간과 파일을 열었을 때의 프로세스 PSS 및 누적 `gfxinfo` 프레임 시간입니다.

실물 기기·ARM ABI·16KiB 페이지 OS·TalkBack 실제 발화는 이번 검사에 포함하지 않았습니다. 열기·프레임 수치는 에뮬레이터 관측값이며, 직전 버전과의 반복 성능 비교나 30분 장시간 검사는 이번 UI 문구 변경에서 수행하지 않았습니다.
