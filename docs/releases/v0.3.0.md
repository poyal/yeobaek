# 여백 v0.3.0

TXT·PDF·만화를 읽는 설정과 폴더 탐색을 강화하고, 독서 기록 수동 백업을 추가했습니다. TXT에서 앞뒤 본문을 불러오는 동안 읽던 위치가 밀릴 수 있는 문제를 수정했습니다.

## 읽기 설정과 화면

- 독서 중 **설정**에서 빠르게 조절하고, **자세한 읽기 설정**에서 전체 옵션을 변경합니다.
- `책 → 바로 위 폴더 → 형식별 공통값` 순으로 설정합니다. 바꾼 항목만 별도로 저장하고 **상속**으로 되돌릴 수 있습니다. 하위 폴더에는 자동 전파하지 않습니다.
- 독서 화면 전용 밝기, 회전 잠금과 화면 켜두기를 추가했습니다.
- TXT 글꼴·굵기 선택을 6가지로 늘렸습니다. 기기의 한글 대체 글꼴에 따라 일부 선택지는 비슷하게 보일 수 있습니다.
- 홈 화면 앱 아이콘의 크기를 줄여 여백을 확보했습니다.

## 만화와 폴더 탐색

- 세로 화면의 좌우 넘김에서 가로로 긴 펼침면을 반쪽씩 읽습니다. 원본 페이지 번호와 읽던 반쪽을 함께 보존합니다.
- 수동·자동 여백 자르기와 페이지별 예외를 추가했습니다. 미리보기에서 조절하며 원본 파일은 변경하지 않습니다.
- 현재 폴더의 파일명 검색, 이름·최신·크기순 정렬, 즐겨찾기, 독서 진행 상태와 파일 미리보기를 추가했습니다.
- 다른 앱에서 전달한 TXT·PDF·이미지·지원 압축파일을 바로 엽니다. 외부 이미지 한 장은 독립 문서로 읽습니다.

## 기록 백업과 스크롤 진단

- **설정 → 일반 설정 → 독서 기록 백업**에서 읽기 위치·책갈피·설정·즐겨찾기를 JSON으로 저장하고 가져옵니다. 복원 전에 내용을 확인하고 기존 기록을 우선 보존합니다.
- 원본 책·캐시·진단 로그와 OS 파일 접근 권한은 백업에 포함하지 않습니다. 다른 기기에서는 **파일 다시 찾기**로 원본을 재연결합니다.
- TXT 본문 교체와 선행 로드가 겹칠 때 읽던 문장이 밀리는 경합을 수정했습니다.
- **설정 → 앱 정보·문의 → 스크롤 진단 로그 저장**을 추가했습니다. 최대 128MiB를 기기에 순환 보관하며 책 이름·본문은 기록하지 않습니다. 문제가 생긴 날짜·시분과 함께 로그를 전달할 수 있습니다. 갤럭시 실기기의 모든 역방향 스크롤 원인이 해결됐다는 뜻은 아닙니다.

## 업데이트와 지원 범위

Android 11 이상, 버전 `0.3.0` / `versionCode 3`입니다. 기존 공개 버전과 같은 서명 키를 사용합니다. 앱의 **설정 → 업데이트**를 이용하거나 APK를 내려받아 기존 앱 위에 설치합니다.

공개 v0.2.0에서 삭제 없이 업데이트하여 DB 3→4 이전, TXT·PDF·만화 기록과 책갈피, 설정, 폴더 접근 권한 및 이어 읽기 보존을 확인했습니다.

EPUB, TXT 자동 목차, 신규 형광펜·메모, TTS·자동 스크롤·리모컨은 포함하지 않습니다. 갤럭시 실기기 터치·성능과 TalkBack 실제 발화, 16KiB 페이지 OS는 이번 검증 범위에 포함되지 않습니다.
