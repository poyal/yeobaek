## 환경과 덮어 설치

전용 AOSP 에뮬레이터 Android 11(API 30)과 Android 16(API 36), x86_64, 720×1600·320dpi·60Hz에서 실행했습니다. 두 환경의 상세 정보는 API 30, API 36에 있습니다. 생성한 TXT·EPUB·PDF·이미지 자료만 사용하며 합성 fixture를 사용했습니다.

직전 공개 APK 0.4.0에 TXT·PDF·이미지의 위치·책갈피와 형식별 설정을 저장한 뒤 최종 1.0.0 APK를 삭제 없이 설치했습니다. DB 스키마는 5로 같고 모든 기존 테이블·열의 값, 설정 파일, 영속 SAF 권한, TXT 외부 원본 해시가 유지됐습니다. 빈 EPUB 위치·책갈피 테이블도 비교했으나 EPUB 기존 독서 데이터가 포함된 덮어 설치를 의미하지는 않습니다. 새 실행에서 이어 읽기 확인, 50% 이후 위치, 책갈피, 글자 크기 19, 어두운 테마를 실제 UI로 확인했습니다. 설치 전 자료, 마이그레이션 직후 자료, 이어 읽기 화면, 복원된 본문.

## 실제 UI와 복원 증거

최적화된 release APK로 밝게·어둡게 각각 실제 폴더 선택, 서재·하위 폴더, 본문 검색, 책갈피, 인코딩, 글꼴·종이 설정, 이어 읽기, 회전을 검사했습니다. 밝은 독서 화면, 어두운 독서 화면, 검색, 가로 회전을 확인했습니다. 앱 정보·업데이트 화면에서는 두 테마 모두 시스템 글자 배율 1.0/2.0에서 탐색·뒤로 가기·버튼 접근을 검사했습니다. 큰 글씨 업데이트 화면, 큰 글씨 앱 정보 화면. 게시 전 촬영본이므로 최신 확인 버전은 당시 공개 버전 0.4.0으로 표시됩니다.

밝은 테마의 프로세스 종료 검사는 실제 `am kill` 후 PID 6257→6351 변경을 확인했습니다. 프로세스 증거. 기기 재부팅은 이전 boot ID와 이후 boot ID가 다르며, 전후 복원 검사에서 시작 폴더·테마·위치·책갈피가 유지됐습니다.

본문도 시스템 글자 200%와 큰 글씨·키보드가 열린 검색 화면을 확인했습니다. 자동 검사가 끝난 뒤 당시 화면을 직접 검토했으며, TalkBack의 실제 발화 검사는 포함하지 않습니다.

## TXT 연속 읽기와 용량

최종 release APK의 50MiB TXT에서 1,800,908ms 동안 양방향 스와이프 1,939회를 수행했습니다. 각 스와이프 후 본문이 정지할 때까지 기다리고 표시 블록이 의도한 방향으로 이동했는지 검사했습니다. 앱 PID 3645가 유지됐으며 화면 이탈·오류·프로세스 재시작은 검출되지 않았습니다. PSS 8개 표본은 69,348~94,118KiB, 시작 73,511KiB·종료 69,348KiB였습니다. Android 11의 파일 선택기 기록을 초기화한 뒤 실제 SAF로 자료 폴더에 연결했습니다.

종료 시점 `gfxinfo`의 프레임 시간 P50/P95/P99는 5/15/29ms였습니다. 이는 60Hz AOSP 에뮬레이터의 프레임 시간이며 `frameOverrunMs`나 실제 갤럭시의 프레임·발열·배터리 성능 측정이 아닙니다. 실물 성능 목표의 통과로 표시하지 않습니다.

Android 16에서 1MiB TXT를 100회 다시 열었으며 자동화가 측정한 열기 시간 P50/P95/P99는 1,122/1,502/2,054ms였습니다. 별도의 용량 검사는 1·10·50·100MiB, 줄바꿈 없는 1MiB 문단, 많은 빈 줄, 결합문자를 열고 약 80% 위치 이동과 양방향 스크롤을 수행했습니다. 101MiB 파일은 용량 제한 안내를 확인했습니다. 열기 시간에는 UI 자동화와 준비 완료 대기가 포함되며 실물 기기의 벤치마크 수치로 해석하지 않습니다.

## 공개 산출물과 업데이트

태그 `v1.0.0`은 문서 포함 커밋 `7c9aff6d57a02a08ffe13b2be98ef8ce0d24adab`을 가리킵니다. 앱을 만든 기준 커밋 이후에는 EPUB 외부 테스트 탐색 보완과 문서·증거만 추가됐으며, 고정한 release APK를 다시 빌드하지 않았습니다.

GitHub 초안에 APK 73,917,353바이트와 체크섬 85바이트를 올리고, 파일명·크기·GitHub SHA-256 digest·체크섬 한 줄·재다운로드 전체 바이트를 대조했습니다. 공개 후에는 인증 없이 최신 릴리즈 API와 공개 다운로드 URL로 같은 검사를 통과했습니다. 실제 release 앱에서도 수동 업데이트 확인 후 현재 버전과 최신 확인 버전이 모두 1.0.0이고 최신 버전 안내가 표시됐습니다. 게시 이후 확인 증거는 main에 문서 커밋으로 추가하며 릴리즈 태그는 유지합니다.

## 범위와 한계

스크롤 회귀 자료는 2026-10-17 12:53:16의 진단 로그에서 추출한 시간·세로 좌표입니다. 정지 상태에서 플링이 차단되고 읽던 위치가 유지되는지 검사합니다. 로그의 반올림된 좌표를 재생하는 것이며, 해당 갤럭시에서 나타난 30,000px/s 산출 자체의 에뮬레이터 재현을 주장하지 않습니다.

실물 갤럭시에서의 수정 효과, 실물 기기의 프레임·배터리·발열, TalkBack 실제 발화, 16KiB 페이지 OS, 실제 구매 EPUB·출판사별 서식은 이번 자동 검사 범위 밖입니다. Android 11 AOSP 파일 선택기의 이전 폴더 복원 시 선택 버튼 누락은 기존 환경 제약에 기록돼 있습니다. EPUB 30분 반복은 이번 TXT 변경에 대해 다시 실행하지 않으며 0.4.0 결과를 새 버전 결과로 표시하지 않습니다.
