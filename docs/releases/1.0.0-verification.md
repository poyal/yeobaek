## 환경과 덮어 설치

전용 AOSP 에뮬레이터 Android 11(API 30)과 Android 16(API 36), x86_64, 720×1600·320dpi·60Hz에서 실행했습니다. 두 환경의 상세 정보는 [API 30](1.0.0-evidence/device-api30.json), [API 36](1.0.0-evidence/device-api36.json)에 있습니다. 생성한 TXT·EPUB·PDF·이미지 자료만 사용하며 [fixture 해시](1.0.0-evidence/fixtures.json)를 보관합니다.

직전 공개 APK 0.4.0에 TXT·PDF·이미지의 위치·책갈피와 형식별 설정을 저장한 뒤 최종 1.0.0 APK를 삭제 없이 설치했습니다. DB 스키마는 5로 같고 모든 기존 테이블·열의 값, 설정 파일, 영속 SAF 권한, TXT 외부 원본 해시가 유지됐습니다. 빈 EPUB 위치·책갈피 테이블도 비교했으나 EPUB 기존 독서 데이터가 포함된 덮어 설치를 의미하지는 않습니다. 새 실행에서 이어 읽기 확인, 50% 이후 위치, 책갈피, 글자 크기 19, 어두운 테마를 실제 UI로 확인했습니다. [설치 전 자료](1.0.0-evidence/upgrade-before.json), [마이그레이션 직후 자료](1.0.0-evidence/upgrade-after-migration.json), [이어 읽기 화면](1.0.0-evidence/upgrade-resume.png), [복원된 본문](1.0.0-evidence/upgrade-reader.png).

기존 자료를 준비하는 도중 두 번의 UI 자동화 실패가 있었습니다. 구형 보조 스크립트가 설정 버튼 위치와 긴 목록의 스크롤 폭을 잘못 가정했으며, 보조 스크립트의 탐색 범위를 수정해 다시 준비했습니다. [첫 실패](1.0.0-evidence/upgrade-seed-failure.txt), [목록 탐색 실패](1.0.0-evidence/upgrade-seed-scroll-failure.txt)를 남겼고 앱 소스·고정 APK는 바꾸지 않았습니다.

## TXT 연속 읽기와 용량

최종 release APK의 50MiB TXT에서 1,800,908ms 동안 양방향 스와이프 1,939회를 수행했습니다. 각 스와이프 후 본문이 정지할 때까지 기다리고 표시 블록이 의도한 방향으로 이동했는지 검사했습니다. 앱 PID 3645가 유지됐으며 화면 이탈·오류·프로세스 재시작은 검출되지 않았습니다. PSS 8개 표본은 69,348~94,118KiB, 시작 73,511KiB·종료 69,348KiB였습니다. Android 11의 파일 선택기 기록을 초기화한 뒤 실제 SAF로 자료 폴더에 연결했습니다.

종료 시점 `gfxinfo`의 프레임 시간 P50/P95/P99는 5/15/29ms였습니다. 이는 60Hz AOSP 에뮬레이터의 프레임 시간이며 `frameOverrunMs`나 실제 갤럭시의 프레임·발열·배터리 성능 측정이 아닙니다. 실물 성능 목표의 통과로 표시하지 않습니다.

Android 16에서 1MiB TXT를 100회 다시 열었으며 자동화가 측정한 열기 시간 P50/P95/P99는 1,122/1,502/2,054ms였습니다. 별도의 [용량 검사](1.0.0-evidence/load-summary.json)는 1·10·50·100MiB, 줄바꿈 없는 1MiB 문단, 많은 빈 줄, 결합문자를 열고 약 80% 위치 이동과 양방향 스크롤을 수행했습니다. 101MiB 파일은 용량 제한 안내를 확인했습니다. 열기 시간에는 UI 자동화와 준비 완료 대기가 포함되며 실물 기기의 벤치마크 수치로 해석하지 않습니다.

## EPUB 자동화 실패와 재검증

EPUB 첫 두 실행은 백업 가져오기에서 복원 확인 화면을 찾지 못해 실패했습니다. [첫 실행](1.0.0-evidence/api36-epub-light-1792212948327629800/summary.json), [파일 선택기 기록 초기화 후 실행](1.0.0-evidence/api36-epub-light-1792213132462896800/summary.json). 실패 캡처는 각각 [Download 폴더 목록](1.0.0-evidence/api36-epub-light-1792212948327629800/device/screens/EPUB-LIGHT/FAIL-backupFreshRestoreAndChangedOriginalKeepRecords.png)과 [Android 최근 앱 화면](1.0.0-evidence/api36-epub-light-1792213132462896800/device/screens/EPUB-LIGHT/FAIL-backupFreshRestoreAndChangedOriginalKeepRecords.png)이었으며 앱 복원 화면에 도달하지 않았습니다.

검사 코드가 목록 맨 아래에서 일부만 보이는 파일 제목도 클릭하도록 돼 있었습니다. 두 화면과 클릭 조건을 근거로, 시스템 탐색 버튼 영역을 누른 것으로 판단했습니다. 테스트의 `selectDocument`만 수정하여 파일 목록 안에서 제목이 충분히 보일 때 클릭하고, 잘린 항목은 스크롤 후 다시 탐색하도록 했습니다. 테스트 APK만 다시 빌드했으며 최종 앱 APK의 SHA-256은 변경 전후 동일합니다. 실패 실행은 성공 수에 합산하지 않습니다.

수정 후 기존 파일 선택기 기록을 유지한 전체 EPUB 3개 검사는 모두 통과했습니다. [새 실행 원시 로그](1.0.0-evidence/api36-epub-light-1792213454621127600/instrumentation.txt), [복원 확인 화면](1.0.0-evidence/api36-epub-light-1792213454621127600/device/screens/EPUB-LIGHT/17-restore-preview.png), [복원된 책갈피](1.0.0-evidence/api36-epub-light-1792213454621127600/device/screens/EPUB-LIGHT/18-restored-bookmark.png). 이번 테스트 탐색 보완의 영향을 받지 않는 나머지 검사는 반복하지 않았습니다. 최종 성공한 release 실제 UI 검사는 위 표를 합해 17개입니다.

## 공개 산출물과 업데이트

태그 `v1.0.0`은 문서 포함 커밋 `7c9aff6d57a02a08ffe13b2be98ef8ce0d24adab`을 가리킵니다. 앱을 만든 기준 커밋 이후에는 EPUB 외부 테스트 탐색 보완과 문서·증거만 추가됐으며, 고정한 release APK를 다시 빌드하지 않았습니다.

GitHub 초안에 APK 73,917,353바이트와 체크섬 85바이트를 올리고, 파일명·크기·GitHub SHA-256 digest·체크섬 한 줄·재다운로드 전체 바이트를 대조했습니다. 공개 후에는 인증 없이 최신 릴리즈 API와 공개 다운로드 URL로 같은 검사를 통과했습니다. 실제 release 앱에서도 수동 업데이트 확인 후 현재 버전과 최신 확인 버전이 모두 1.0.0이고 최신 버전 안내가 표시됐습니다. 게시 이후 확인 증거는 main에 문서 커밋으로 추가하며 릴리즈 태그는 유지합니다.

## 범위와 한계

스크롤 회귀 자료는 2026-10-17 12:53:16의 진단 로그에서 추출한 시간·세로 좌표입니다. 정지 상태에서 플링이 차단되고 읽던 위치가 유지되는지 검사합니다. 로그의 반올림된 좌표를 재생하는 것이며, 해당 갤럭시에서 나타난 30,000px/s 산출 자체의 에뮬레이터 재현을 주장하지 않습니다.

실물 갤럭시에서의 수정 효과, 실물 기기의 프레임·배터리·발열, TalkBack 실제 발화, 16KiB 페이지 OS, 실제 구매 EPUB·출판사별 서식은 이번 자동 검사 범위 밖입니다. Android 11 AOSP 파일 선택기의 이전 폴더 복원 시 선택 버튼 누락은 [기존 환경 제약](0.4.0-verification.md)에 기록돼 있습니다. EPUB 30분 반복은 이번 TXT 변경에 대해 다시 실행하지 않으며 0.4.0 결과를 새 버전 결과로 표시하지 않습니다.
