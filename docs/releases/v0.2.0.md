# 여백 0.2.0 — 릴리즈 노트 초안

상태: 소스 준비 및 로컬 검증. 공개 릴리즈와 태그는 아직 생성하지 않았습니다. 게시 전 [검증 기록과 남은 서명 검사](0.2.0-verification.md)를 확인합니다.

## 추가 기능

- **PDF 뷰어**: 세로 스크롤, 확대, 페이지 이동, 검색·선택·복사, 책갈피·이어 읽기, 이미지와 도표를 포함한 색상 반전.
- **이미지 뷰어**: 이미지 폴더와 ZIP/CBZ·RAR/CBR·7Z/CB7, 자연스러운 파일명 순서, 세로 스크롤·좌우 넘김·읽는 방향·두 쪽 보기, 썸네일·목차·책갈피·이어 읽기·색상 반전.
- TXT·PDF·이미지를 끝까지 읽으면 **다음 것 보기 / 나가기**를 안내합니다. 현재 폴더의 다음 지원 항목으로 이어지며 마지막 항목에서는 나가기만 표시합니다.

## 화면 개선

- 바깥 하단 탐색을 **홈 · 최근 읽기 · 설정**으로 변경하고 홈 아이콘을 적용했습니다.
- 뷰어 하단 메뉴의 이름·아이콘·배치·터치 영역을 통일했습니다. **이동 · 책갈피**는 앞쪽, **설정**은 마지막에 표시하며 검색·정보·색상 반전은 지원 형식에 맞게 제공합니다.
- 읽기 설정을 전체 화면으로 열고, 일반 설정과 뷰어 설정을 분리했습니다. 일반 설정은 앱 테마와 폴더·저장 공간으로 묶었습니다.
- 초기화·연결 해제 등 주의가 필요한 동작을 빨간 버튼으로 구분했습니다. 홈 필터는 상태가 바뀌는 아이콘으로 표시합니다.
- 이어 읽기의 긴 제목은 최대 두 줄과 말줄임으로 표시하고 부가 설명을 제거했습니다. 긴 파일·폴더 이름도 화면을 밀어내지 않도록 정리했습니다.

## 지원 범위와 업데이트

Android 11 이상, 버전 `0.2.0` / `versionCode 2`입니다. 기존 공개 앱 위에 설치하려면 **v0.1.0과 같은 서명 키**로 빌드해야 합니다. 앱을 삭제하면 로컬 독서 기록이 사라질 수 있으므로 업데이트 검증은 삭제 없이 수행합니다.

PDF의 좌우 넘김·두 쪽 보기·편집·주석·서명·암호 문서, 이미지 OCR·편집·암호/분할/중첩 압축은 지원하지 않습니다. 실물 기기 성능·TalkBack·16KiB 페이지 OS 검증은 별도 인수가 필요합니다.

게시할 때 검증을 마친 APK를 `yeobaek-0.2.0.apk`로 고정하고, 같은 파일의 SHA-256을 `yeobaek-0.2.0.sha256`에 기록합니다. 현재 Mac의 로컬 서명 검증 APK는 기존 공개 앱과 인증서가 달라 배포용 업데이트 파일로 사용할 수 없습니다.
