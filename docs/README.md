# 여백 사전조사 문서

문서의 **확인 사실**은 공식 문서·개발사 자료·기존 Android 프로젝트의 소스 검토를 바탕으로 합니다. **설계 제안**과 **목표 수치**는 여백을 위한 판단이며, 구현·실기기 측정으로 확정해야 합니다. 실제 구현은 [구현 문서](implementation.md), 로컬 실행 증거와 실물 기기 미실행 항목은 [검증 기록](releases/0.1.0-verification.md)에 분리했습니다.

조아라·노벨피아는 사용자께서 지정하신 스크롤 경험의 참고 대상입니다. 해당 앱이 사용하는 내부 기술이나 성능을 추정해 사실로 기록하지 않습니다.

기존 프로젝트에서 필요한 개발·UI·검증 경험은 여백 기준으로 고쳐 본문에 직접 옮겼습니다. 다른 프로젝트 폴더나 문서를 열지 않아도 이 문서들로 후속 구현을 진행할 수 있습니다.
