# 대용량 PDF 검증 · 2026-10-14

Android 11(API 30)·16(API 36) ARM64 에뮬레이터에서 실제 106.77MiB 혼합 PDF와 302.54MiB 스캔 PDF가 모두 통과했습니다. 각 환경의 부하 검사 2개와 PDF/TXT 회귀 검사 10개가 성공했습니다. 두 환경을 합쳐 120회 반복 조작, 40회 문서 재열기를 수행했습니다.

## 시험 자료와 조건

| 파일 | 실제 크기 | 페이지 | 내용 |
|---|---:|---:|---|
| `100MiB-mixed.pdf` | 111,961,021바이트 / 106.77MiB | 12 | 페이지마다 고유 JPEG와 검색 가능한 텍스트 |
| `300MiB-scan.pdf` | 317,234,913바이트 / 302.54MiB | 34 | 페이지마다 고유 JPEG, 텍스트 층 없음 |

각 JPEG는 2048×2816입니다. 실제 표시하는 이미지 스트림이 파일 크기의 99% 이상이며, 빈 데이터나 동일 이미지 참조로 용량을 늘리지 않았습니다. 기존 500페이지 작은 합성 PDF도 일반 회귀 검사에서 마지막 페이지 이동·확대 렌더링을 확인했습니다.

부하 검사는 debug APK와 실제 앱의 복사·해시·격리 렌더러·네이티브 뷰·검색·위치 저장 코드를 사용합니다. API 30은 1080×2280, API 36은 720×1600이며 둘 다 density 320입니다. Java 힙 한도는 192MiB, 화면 타일 캐시 한도는 24MiB였습니다. 두 환경의 부하 검사는 순서대로 실행했습니다.

## 검사 범위

- 문서마다 앱 캐시를 비우고 복사·해시·페이지 확인·첫 타일 표시 3회.
- 대용량 복사 중 취소 후 임시 파일이 남지 않는지 검사.
- 첫 화면의 모든 타일 표시, 1·2·5배 확대, 색상 반전, 페이지 이동과 스와이프를 묶어 30회 반복. 핀치와 두 번 탭도 포함.
- 화면 조작과 동시에 전체 검색. 완료 시각은 UI 테스트 스레드와 분리해서 측정하며 60초 제한을 적용.
- 마지막 페이지·확대율 저장 후 문서 닫기, 재열기와 저장 페이지 타일 렌더링 10회.
- 타일 실패·메모리 한도·반복 중 메모리 증가·파일 디스크립터 증가·원본 SHA-256 보존 검사.

## 결과

아래 열기 시간은 앱 캐시 복사·해시부터 첫 타일까지의 합계입니다. OS 파일 캐시는 비우지 않았습니다. 첫 화면 시간은 별도로 문서를 준비한 후 뷰 생성부터 화면 타일 완성까지 측정했습니다.

호스트에서 앱과 격리 렌더러를 별도로 조회한 PSS 표본의 최고값입니다. 합산 값은 각 조회 구간의 두 프로세스 PSS를 더한 값입니다.

모든 화면 타일 캐시가 24MiB 이내였습니다. 초기 안정 구간 대비 마지막 구간의 PSS 중앙값 증가는 최대 약 3.3MiB로 96MiB 기준 이내였고, 앱 파일 디스크립터 증가는 최대 2개로 24개 기준 이내였습니다. 모든 실행에서 원본 해시가 유지됐고, 렌더링 실패·메모리 한도 초과·프로세스 충돌은 없었습니다.

반복 조작 묶음의 P95는 API 30 혼합/스캔 3.235/3.374초, API 36 혼합/스캔 8.556/12.434초였습니다. 재열기와 한 타일 렌더링 P95는 각각 0.163/0.239초와 0.767/2.059초였습니다. P95는 nearest-rank 방식이며 조작 묶음에는 이동·스와이프와 일부 핀치/두 번 탭이 포함됩니다. 프레임 시간이나 단일 탭 응답 시간으로 해석하지 않습니다.

## 함께 반영한 개선과 회귀 검사

대용량 이미지의 타일마다 페이지를 열고 닫던 처리를 최근 2개의 네이티브 페이지를 재사용하도록 바꿨습니다. 문서별로 구분하고, 퇴출·문서 닫기·서비스 종료 시 페이지를 해제합니다. 별도 회귀 검사는 두 문서를 함께 열어 캐시 퇴출 후에도 픽셀이 같은지, 다른 문서를 닫아도 검색·렌더링이 유지되는지, 다시 열 수 있는지 확인합니다.

각 OS에서 PDF 렌더링·반전·검색·선택·취소·오류·500페이지 이동·위치 보존·DB 이관·설정 초기화와 TXT 기록 저장까지 10개 검사가 통과했습니다. 코어 단위 테스트 9개와 앱 단위 테스트 19개도 통과했습니다. Lint는 오류 0개, 경고 35개로 완료됐으며 경고에는 의존성 업데이트·KTX 권장·그리기 중 할당·커스텀 뷰 접근성 항목이 남아 있습니다. release 빌드와 16KB ZIP 정렬 검사를 통과했습니다.
