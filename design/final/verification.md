# 확정 시안 확인 기록

확인일: 2026-10-13. 대상은 로컬 HTML/CSS/JavaScript 시안입니다.

## 디자인 1.1 — 리듬 확정 및 폴더 통합

- 앱 화면과 **리듬(3차 04)** 아이콘을 `design/final/`에 통합했습니다. 최종 심볼의 경로 문자열이 선택된 원본과 정확히 일치합니다.
- 서재 제목·설정 하단·디자인 표지·라이트/다크 비교판에 같은 심볼을 적용했습니다.
- 이전 앱 시안 5종과 아이콘 시안 3차분을 `design/archive/`에 모았습니다. 확정본 JavaScript는 보관 폴더에 의존하지 않습니다.
- 라이트·다크 핵심 6화면과 폴더·시작 폴더·테마 분리·TXT 초기화·이어 읽기·검색·책갈피·인코딩·기록 삭제·이동 흐름 검사를 다시 통과했습니다.
- 본문 탭·Enter 메뉴 토글, 위치 유지, 이동 적용·취소, 터치 스와이프·길게 누르기 구분을 다시 확인했습니다.
- 전체 HTML 18개에서 스크립트 실행과 이미지 로드를 확인했고 JavaScript 오류는 0건입니다. 새 진입 페이지·브랜드·비교판·보관 시안 안내는 390px·360px에서 가로 넘침이 없습니다.
- HTML·Markdown 45개에 포함된 로컬 링크 322개를 검사했습니다. 잘못된 경로는 없으며 이동 전 폴더를 가리키는 참조도 남아 있지 않습니다.
- 확정 폴더에는 SVG 7개, PNG 18개가 있습니다. 라이트·다크 최종 조합, 브랜드 비교, 모바일 서재를 직접 살펴보았습니다.

## 브라우저 확인

Chromium에서 라이트·다크 각각 다음 항목을 확인했습니다.

| 항목 | 결과 |

| 인코딩 | CP949 선택 후 해당 책 정보에 표시 |
| 기록 삭제 | 명시적인 확인 후 최근 기록 제거, 폴더의 원본 예시 항목 유지 |
| 큰 본문 글자 | 390px 창에서 최대 크기 32 적용, 본문 가로 넘침 없음, 초기화 가능 |

## 색상 대비

CSS의 실제 16진수 색상을 sRGB 상대 휘도로 변환해 계산했습니다. 텍스트는 4.5:1, 의미 있는 조작 윤곽은 3:1을 이 제품의 확인 기준으로 사용했습니다.

| 조합 | 라이트 | 다크 |
| --- | --- | --- |
| 본문 / 기본 배경 | 11.26:1 | 13.17:1 |
| 보조 글자 / 기본 배경 | 5.29:1 | 7.03:1 |
| 보조 글자 / 보조 표면 | 4.93:1 | 5.92:1 |
| 보조 글자 / 선택 카드 | 4.60:1 | 4.85:1 |
| 강조 글자 / 선택 카드 | 5.17:1 | 6.08:1 |
| 채운 버튼 글자 / 버튼 | 6.36:1 | 8.30:1 |
| 삭제 문구 / 대화상자 | 6.27:1 | 7.18:1 |
| 조작 윤곽 / 기본 배경 | 3.60:1 | 5.29:1 |
| 조작 윤곽 / 대화상자 | 3.85:1 | 4.37:1 |

두 모드의 위 18개 조합이 기준을 충족합니다. 장식용 구분선, 비활성 표시, 합성 레이어 전체, 모든 가능한 상태를 통합 검증한 접근성 인증은 아닙니다.
