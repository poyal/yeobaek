# 여백 — 확정 디자인

**종이의 여백 × 리듬**으로 앱 화면과 브랜드 아이콘을 확정했습니다. 최신 구현 기준은 `final/` 한 폴더입니다.

[확정 앱 시안](final/index.html) · [라이트·다크 비교](final/comparison.html) · [확정 아이콘](final/brand.html) · [디자인 명세](final/README.md)

```text
design/
├── index.html           확정 디자인 안내
├── final/               확정 화면·아이콘·디자인 명세
│   ├── index.html       앱 시연
│   ├── comparison.html  라이트·다크 최종 조합
│   ├── brand.html       리듬 아이콘과 이름 조합
│   ├── brand.js         확정 심볼 원본
│   ├── assets/          확정 SVG 7개
│   ├── previews/        확정 화면·아이콘 PNG
│   ├── README.md        구현 기준과 브랜드 사용 규칙
│   └── verification.md  확인 기록
└── archive/             이전 시안을 모은 보관 폴더
    ├── app-studies/     초기 앱 디자인 5종과 공통 리소스
    ├── icons-v1/        첫 번째 아이콘 시안
    ├── icons-v2/        두 번째 아이콘 시안
    └── icons-v3/        세 번째 아이콘 시안과 선택 기록
```

아이콘은 3차 시안의 **04 리듬**입니다. 선택된 도형을 그대로 사용하며, 라이트·다크 색상과 단색 전경을 함께 제공합니다. 앱 이름은 **여백**이고 ‘리듬’은 심볼의 이름입니다.

기존 시안은 삭제하지 않고 [archive/](archive/index.html)에 모았습니다. 보관 폴더의 예전 화면·이미지는 비교 기록이며, 구현에서는 [final/README.md](final/README.md)를 따릅니다.
