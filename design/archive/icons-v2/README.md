아기자기한 방향으로는 **05 고요한 고양이**, 기존 앱의 차분한 분위기와 ‘읽는 시간, 나만의 자리’ 문구에는 **04 나만의 자리**가 잘 맞습니다. 이는 비교 의견이며 최종 아이콘 확정은 아닙니다.

## 형태 기준

- 도형은 모두 직접 그린 SVG이며 외부 이미지·아이콘 세트·글꼴을 사용하지 않습니다.
- 한 아이콘에 하나의 중심 소재를 둡니다. 공통 팔레트를 적용해 형태 차이를 비교합니다.
- 라이트는 올리브 `#536348` + 종이색 `#F8F5EF`, 다크는 `#292F25` + `#E3EAD8`입니다.
- 108×108 좌표계의 중앙 66×66 범위 안에 핵심 형태를 배치합니다. 중요한 틈과 획을 굵게 잡고 48·32·24px 및 단색으로 확인합니다.
- 찻잔의 손잡이와 고양이의 표정은 실제로 뚫린 빈 공간입니다. 배경색을 덧칠하지 않아 투명 전경·단색에서도 유지됩니다.
- 바탕과 전경을 분리하며 파일 자체에는 둥근 모서리를 고정하지 않습니다. 갤러리의 둥근 사각형·원형·스퀴클은 형태 검토용 마스크입니다.

여기서 라이트·다크는 디자인 조합입니다. 앱 UI의 테마 변경과 런처 아이콘의 변경을 연결한 구현은 아닙니다.

## 비교 페이지

`index.html`을 브라우저에서 열면 인터넷·서버 없이 동작합니다.

1. 라이트·다크, 세 가지 모서리 형태를 비교합니다.
2. 후보별 `앱과 함께 보기`를 누르면 아래 브랜드 표식과 홈 화면 예시가 바뀝니다.
3. 확정된 앱의 폴더 서재·TXT 독서 화면 옆에서 색감과 인상을 확인합니다.
4. 선택된 후보의 SVG와 1024px PNG를 다운로드합니다.

직접 열 때 `?icon=05-quiet-cat&theme=dark`처럼 특정 후보·모드를 지정할 수 있습니다. 앱 미리보기는 기존 확정 화면의 캡처입니다.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `catalog.js` | 5종 아이콘의 원본 경로, 이름·설명, 공통 팔레트 |

ID는 `01-story-door`, `02-daily-cup`, `03-growing-thought`, `04-reading-chair`, `05-quiet-cat`입니다. SVG 27개와 PNG 18개를 제공합니다. 기존 시안은 [이전 폴더](../icons-v1/index.html)에 있습니다.

현재 결과물은 아이콘 디자인 시안입니다. 선택한 다음 앱 전체의 브랜드 표식과 최종 조합을 정리합니다.

## 확인 결과

Chromium에서 5종 후보 선택, 라이트·다크, 세 가지 마스크, 다운로드 대상, URL의 후보·테마 지정을 확인했습니다. 갤러리의 1600px·390px 화면과 비교 페이지의 390px 화면에서 가로 넘침이 없고, JavaScript 실행 오류는 0건입니다. SVG 27개의 XML 구조와 전경 투명성, HTML 로컬 링크 14개를 검사했습니다. PNG 18개를 생성하고 라이트·다크 전체 비교와 앱 조합을 눈으로 확인했습니다.
