후속 작업은 [새로운 아이콘 시안 5종](../icons-v2/index.html)입니다. 이 폴더는 첫 번째 비교 기록입니다.

2026-10-13. ‘종이의 여백’ 라이트·다크 앱 디자인과 조합하기 위한 **선택 전 후보**입니다. 기존 다섯 앱 디자인을 다시 만드는 작업이 아니라, 선택된 앱에 사용할 런처·브랜드 아이콘을 비교합니다.

## 비교 페이지 사용

- 라이트·다크 전환으로 배경과 아이콘 색상을 함께 확인합니다.
- 둥근 사각형·원형·스퀴클의 형태를 비교합니다. 마스크는 브라우저 검토용 근사 형태입니다.
- 각 후보에서 48·32·24px와 단색 형태를 확인합니다.
- `앱과 함께 보기`를 누르면 아래 조합 패널·홈 화면 예시·다운로드 파일이 변경됩니다.
- 옆에는 현재 확정 앱의 실제 HTML 캡처를 표시합니다. 본문 탭 메뉴 토글·상단 퍼센트·하단 이동 변경까지 반영한 화면입니다.
- SVG와 1024px PNG는 현재 보고 있는 후보·모드의 파일을 내려받습니다.

앱 화면 자체에 후보를 영구 적용하거나 최종 아이콘을 지정한 상태는 아닙니다. 홈 화면의 다른 앱은 비교를 위한 직접 만든 일반 기호입니다. 자동 저장·서버·외부 폰트·외부 이미지·패키지가 필요하지 않습니다.

## 파일 구성

원본 도형은 [catalog.js](catalog.js)에 있습니다. 다섯 기호 모두 SVG 경로·타원으로 직접 만들었습니다. ‘여’도 폰트 글자가 아니므로 시스템 글꼴 설치 여부에 따라 모양이 달라지지 않습니다.

04번 쉼표는 원과 선을 겹치던 구조를 폐기하고, 하나의 닫힌 SVG 경로로 다시 만들었습니다. 머리 오른쪽에서 꼬리까지 바깥 곡선을 연속으로 그리고, 안쪽 파임에도 둥근 곡선을 적용해 접합부가 꺾여 보이던 부분을 수정했습니다. 같은 윤곽을 라이트·다크·투명 전경·단색 파일에 공통으로 사용합니다.

후보마다 다음 파일을 `assets/`에 제공합니다. `{id}`는 `01-open-book`, `02-yeo-seal`, `03-kept-line`, `04-comma`, `05-flowing-pages`입니다.

| 파일 | 내용 |
| --- | --- |
| `{id}-light.svg` | 배경을 포함한 라이트 조합 |
| `{id}-dark.svg` | 배경을 포함한 다크 조합 |
| `{id}-foreground-light.svg` | 배경 없는 라이트 전경 |
| `{id}-foreground-dark.svg` | 배경 없는 다크 전경 |
| `{id}-monochrome.svg` | 투명 배경·단색 전경 |
| `background-light.svg` / `background-dark.svg` | 공통 배경 레이어 |

색상 전체 아이콘은 `previews/{id}-{mode}-1024.png`에도 저장합니다. PNG는 사각형 전체 배경을 가진 검토용 이미지이며, 모서리 마스크나 그림자를 파일에 구워 넣지 않습니다. `overview.png`는 다섯 후보의 라이트·다크 비교, `{id}-application.png`는 각 후보와 앱을 함께 본 조합 이미지입니다.

## 색상과 형태

| 역할 | 라이트 조합 | 다크 조합 |
| --- | --- | --- |
| 배경 | `#536348` | `#292F25` |
| 기본 기호 | `#F8F5EF` | `#E3EAD8` |
| 보조 종이·획 | `#C7D2B7` | `#A9B99A` |

아이콘의 크기는 108×108 좌표계이고, 핵심 형태는 중앙의 66×66 범위에 두었습니다. 색상 전경·배경과 단색 전경을 분리하는 방식은 [Android 공식 적응형 아이콘 문서](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)를 기준으로 했습니다. 실제 마스크·런처 움직임에서의 안전성은 Android 리소스로 변환한 뒤 확인합니다.

여기서 라이트·다크는 **디자인 색상 조합 비교**입니다. 앱 내부의 테마를 바꾼다고 홈 화면 아이콘이 자동으로 전환된다는 뜻은 아닙니다. Android의 테마 아이콘은 런처·사용자 설정과 단색 레이어 처리에 따르며, 앱 UI 테마와 별개의 기능입니다. [공식 설명](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)

## 선택 후 최종 조합

선택한 기호를 기준으로 기본 런처 색상, 앱 안 브랜드 표식의 크기·배치, 시작 화면의 표식을 정리합니다. 기존 ‘종이의 여백’의 앱 기능·독서 조작은 유지하고, 전체 라이트·다크 시안과 아이콘을 하나의 디자인 명세로 묶습니다.

이번 파일은 디자인 원본입니다. Android VectorDrawable·adaptive-icon XML, Manifest 연결, 스토어 등록 이미지, APK는 아직 만들지 않았습니다.

## 확인 결과

Chromium에서 다섯 후보의 라이트·다크 전환, 세 가지 마스크 전환, 후보별 조합과 다운로드 대상 변경을 확인했습니다. 1600px·390px 화면에서 페이지 가로 넘침이 없으며 JavaScript 실행 오류는 0건입니다. SVG 27개의 XML 구조와 로컬 링크를 검사했고, 쉼표 수정 미리보기를 포함한 PNG 17개를 저장했습니다. 비교 이미지와 앱 조합 이미지는 직접 살펴보았습니다.
