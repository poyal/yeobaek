# 여백 아이콘 — 세 번째 시안 5종

> 보관 기록입니다. 최종 선택은 **종이의 여백 × 리듬(3차 04)**이며, [확정본](../../final/index.html)과 [최신 명세](../../final/README.md)를 구현 기준으로 사용합니다.

2026-10-13. 여백이라는 이름과 읽는 경험에서 출발해 직접 설계한 브랜드 심볼입니다. 형태 안의 빈 공간, 서로 다른 곡률, 어긋난 비율을 각 후보의 특징으로 삼았습니다.

## 다섯 가지 형태

| 번호 | 이름 | 출발점 | 형태에 남긴 특징 |
| --- | --- | --- | --- |
| 01 | 사이 | 여백이라는 이름 | 큰 면과 작은 면 사이를 지나는 비스듬한 통로. 안쪽에서 한 번 꺾이는 틈과 서로 다른 면적이 표식을 만듭니다. |
| 02 | 이어짐 | 다시 이어 읽는 경험 | 기울어진 바깥 고리에서 안으로 돌아드는 하나의 띠. 어긋난 두 끝과 긴 내부 틈으로 방향을 만듭니다. |
| 03 | 품 | 나만의 이야기가 머무는 공간 | 세 방향의 곡률이 다른 둥근 외곽. 한쪽이 더 두꺼운 벽과 비스듬한 내부 공간이 함께 기울어집니다. |
| 04 | 리듬 | 한 문장씩 읽는 보폭 | 높이가 다른 두 사선을 연결한 하나의 획. 위아래의 깊은 파임과 둥근 끝의 대비가 남습니다. |
| 05 | 잔상 | 읽고 난 뒤에도 남는 여운 | 길이·방향·굽음이 다른 세 조각. 완전한 회전 대칭에서 벗어난 면과 사이의 틈으로 묶었습니다. |

이름과의 연결을 우선하면 **01 사이**, 부드러운 형태를 원하면 **03 품**이 잘 맞습니다. 02는 읽기 동작, 04는 선명한 실루엣, 05는 여러 조각으로 이루어진 표식에 무게를 두었습니다. 이 비교에서 **04 리듬이 최종 선택되었습니다.**

## 직접 설계한 부분

모든 심볼의 곡선·꼭짓점·안쪽 빈 공간을 [catalog.js](catalog.js)에 직접 작성했습니다. 아이콘 라이브러리, 폰트 글리프, 외부 로고 원본을 사용하지 않았습니다.

- 01의 통로가 좁아지지 않도록 위쪽 간격과 비스듬한 구간을 분리했습니다.
- 02는 하나의 연속된 경로에 일정한 두께와 둥근 끝을 적용했습니다.
- 03의 가운데는 실제로 뚫린 공간입니다. 바탕색을 덧칠하지 않아 투명 전경에서도 유지됩니다.
- 04는 위아래 파임을 다르게 두고 바깥 끝을 둥글게 마무리했습니다.
- 05는 각 조각의 크기·위치를 개별 조정해 작은 크기에서도 사이의 틈을 읽을 수 있게 했습니다.

비교판에서는 공통 팔레트와 같은 크기를 사용합니다. [심볼 조합판](symbols.html)에서는 배경 컨테이너를 벗긴 단색 실루엣과 ‘여백’ 이름의 조합을 확인합니다.

## 파일과 사용

| 파일 | 내용 |
| --- | --- |
| `catalog.js` | 5종의 원본 벡터 경로·설계 설명·팔레트 |
| `index.html`, `icons.css`, `icons.js` | 라이트·다크, 세 가지 마스크, 후보 선택과 앱 조합 |
| `contact-sheet.html` | 다섯 후보의 라이트·다크 비교 |
| `symbols.html` | 심볼 단독 형태와 앱 이름 조합 |
| `assets/{id}-light.svg`, `{id}-dark.svg` | 배경을 포함한 아이콘 |
| `assets/{id}-foreground-light.svg`, `{id}-foreground-dark.svg` | 투명 전경 |
| `assets/{id}-monochrome.svg` | 검정 단색 전경 |
| `assets/background-light.svg`, `background-dark.svg` | 공통 배경 레이어 |
| `previews/{id}-{mode}-1024.png` | 배경 포함 1024×1024 이미지 10개 |
| `previews/{id}-application.png` | 후보별 앱 조합 5개 |
| `previews/overview.png`, `light.png`, `dark.png` | 전체·모드별 비교 3개 |
| `previews/symbols.png` | 심볼과 이름 조합 1개 |

ID는 `01-between`, `02-continuum`, `03-within`, `04-cadence`, `05-afterglow`입니다. SVG 27개, PNG 19개를 제공합니다.

`index.html`은 서버·인터넷 없이 브라우저에서 열 수 있습니다. `?icon=03-within&theme=dark`처럼 특정 후보·모드로 바로 열 수도 있습니다. 화면에서 후보를 누르면 SVG·PNG 다운로드 대상과 앱 조합이 바뀝니다.

원본 경로를 수정한 뒤 아래 명령으로 SVG 전체를 갱신합니다. PNG는 브라우저에서 다시 캡처합니다.

```sh
node design/archive/icons-v3/export-assets.cjs
```

## 앱 디자인과의 관계

‘종이의 여백’의 올리브·종이색과 따뜻한 다크 팔레트를 유지했습니다. 좌표계는 108×108이며 핵심 형태는 중앙에 배치했습니다. 48·32·24px와 원형 마스크, 단색 형태를 함께 비교합니다.

라이트·다크는 디자인 조합입니다. 앱 UI 테마에 따라 런처 아이콘을 바꾸는 구현은 포함하지 않습니다. 앱 조합에 쓰인 폴더 서재·TXT 독서 화면은 기존 확정 시안의 캡처입니다.

프로젝트의 기본 아이콘 링크는 [확정 아이콘](../../final/brand.html)으로 연결됩니다. [첫 번째 시안](../icons-v1/index.html)과 [두 번째 시안](../icons-v2/index.html)은 각각의 폴더에 보관했습니다.

## 확인 결과

Chromium에서 5종 선택, 라이트·다크, 세 가지 마스크, 다운로드 대상, URL의 후보·테마 지정을 확인했습니다. 갤러리의 1600px·390px, 전체 비교의 390px, 심볼 조합판의 1800px·390px 화면에 가로 넘침이 없고 JavaScript 실행 오류는 0건입니다. SVG 27개의 XML 구조와 전경 투명성, HTML 로컬 링크 18개와 관련 README 링크를 검사했습니다. PNG 19개를 생성하고 전체 비교·단색 심볼·앱 조합을 직접 확인했습니다.
