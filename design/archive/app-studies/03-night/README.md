# 03. 밤의 문장

관점: **야간의 긴 독서**. 디자인 제안이며 구현·기기 검증 결과가 아닙니다.

[인터랙티브 시안](index.html) · [전체 화면 PNG](../previews/03-night.png) · [시안 비교](../README.md)

## 디자인 의도

짙은 바탕에 따뜻한 본문과 필요한 조작만 남깁니다. 야간 독서의 분위기를 중심으로 구성했습니다.

- 시각 언어: 먹색 · 호박빛 · 낮은 화면 밝기.
- 적합한 사용 맥락: 야간 분위기와 몰입.
- 검토할 점: 실제 저조도 가독성과 피로도를 검증한 결과는 아닙니다.

## 포함 화면

폴더 서재, 새 실행의 이어 읽기 확인, TXT 독서, 앱 설정, TXT 전용 설정의 다섯 화면입니다. 색상·글꼴·목록 밀도·이어 읽기 배치·버튼 형태를 함께 비교합니다.

## 공통 제품 규칙

시작 폴더는 앱 설정에서 변경합니다. 원본 파일을 가져오는 대신 연결한 폴더를 탐색합니다. 새 실행에서 독서 후보가 있으면 이어 읽기와 폴더 보기 중 선택합니다. TXT 표시 옵션과 앱 설정은 별도로 저장하며 TXT 초기화는 시작 폴더를 유지합니다. 미구현 PDF·이미지 옵션은 앱 화면에 표시하지 않습니다.

브라우저 시안에서 폴더 선택·파일 내용·검색 결과는 예시로 동작합니다. 실제 SAF·파일 접근·앱 생명주기·문자 앵커 복원·접근성 인증·프레임 성능을 구현하거나 검증한 앱은 아닙니다.
